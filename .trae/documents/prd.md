# 数据看板页面 PRD

## 1. 项目概述

### 1.1 项目名称
数据看板（Dashboard）页面

### 1.2 项目目标
创建一个现代化、简洁的数据可视化看板页面，用于展示销售数据、用户活跃度等关键业务指标。

### 1.3 目标用户
- 企业管理层
- 数据分析师
- 运营人员

## 2. 功能需求

### 2.1 顶部汇总指标卡片
- **用户数**：展示总用户数量，带增长趋势指示
- **转化率**：展示当前转化率百分比
- **日均收入**：展示日均收入金额

### 2.2 销售趋势折线图
- 展示近30天的销售数据趋势
- 支持数据点悬停显示详情
- 平滑曲线展示

### 2.3 地区分布饼图
- 展示不同省份的销售/用户分布
- 彩色分区显示
- 支持悬停查看详细数据

### 2.4 用户活跃度热力图
- 展示日-小时维度的用户活跃度分布
- 颜色深浅表示活跃程度
- 横轴为时间（小时），纵轴为日期

## 3. 技术要求

### 3.1 技术栈
- 纯 HTML/CSS/JavaScript 实现
- 使用 Chart.js 作为图表库
- 响应式设计，支持桌面端优先

### 3.2 性能要求
- 页面加载时间 < 2秒
- 图表渲染流畅，无卡顿

## 4. 设计要求

### 4.1 视觉风格
- 现代简洁的卡片风格
- 统一的配色方案
- 清晰的视觉层次

### 4.2 交互设计
- 图表悬停效果
- 平滑的动画过渡
- 数据提示框

## 5. 数据模拟
使用模拟数据展示，数据结构清晰，便于后续对接真实API。
