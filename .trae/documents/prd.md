## 1. Product Overview

极简在线二维码生成工具 - 用户粘贴网址或文本，即时生成可右键保存的二维码图片。无需注册、登录或安装任何软件。

- 解决用户快速生成二维码的需求，无需复杂操作或注册流程
- 目标用户：需要快速生成二维码的普通用户、营销人员、开发者等

## 2. Core Features

### 2.1 User Roles
无需用户角色区分，所有功能匿名可用。

### 2.2 Feature Module
1. **主页面**: 文本输入框、二维码显示区域、使用提示

### 2.3 Page Details
| Page Name | Module Name | Feature description |
|-----------|-------------|---------------------|
| 主页面 | 输入区域 | 大而清晰的文本输入框，支持HTTP/HTTPS链接及纯文本 |
| 主页面 | 二维码生成 | 用户停止输入1秒后自动生成二维码，无需点击按钮 |
| 主页面 | 二维码显示 | 显示清晰可扫描的二维码图片，支持右键保存为PNG |
| 主页面 | 响应式布局 | 适配桌面、平板、手机等设备 |

## 3. Core Process

用户打开页面 → 在输入框粘贴/输入内容 → 系统自动检测输入 → 1秒防抖后生成二维码 → 显示二维码图片 → 用户右键保存图片

```mermaid
flowchart TD
    "A[用户打开页面]" --> "B[在输入框输入/粘贴内容]"

    "C" -->|否| "E[显示提示信息]"
    "D" --> "F[生成二维码]"
    "F" --> "G[显示二维码图片]"
    "G" --> "H[用户右键保存]"
```

## 4. User Interface Design

### 4.1 Design Style
- **主色调**: 深色主题，以深灰/黑色为背景，白色文字，营造专业、现代感
- **强调色**: 青绿色 (#00D9A5) 作为品牌色，用于按钮、图标等交互元素
- **按钮风格**: 无按钮设计，自动生成，极简交互
- **字体**: 使用 Space Mono 作为品牌字体，JetBrains Mono 作为UI字体，体现技术感
- **布局风格**: 居中对称布局，输入框与二维码并排或上下排列
- **动效**: 输入时边框发光效果，二维码生成时有淡入动画

### 4.2 Page Design Overview
| Page Name | Module Name | UI Elements |
|-----------|-------------|-------------|
| 主页面 | 标题区域 | 居中大标题"QR Generator"，副标题说明用途 |
| 主页面 | 输入区域 | 大尺寸圆角输入框，placeholder提示"粘贴你的网址或文本链接" |
| 主页面 | 二维码区域 | 白色背景卡片，居中显示二维码，带阴影效果 |
| 主页面 | 提示区域 | 小字提示"右键保存图片"，淡灰色 |

### 4.3 Responsiveness
- 桌面优先设计，大屏幕输入框与二维码左右并排
- 平板及以下设备改为上下布局
- 输入框和二维码尺寸自适应屏幕宽度
- 触摸设备优化输入框大小

### 4.4 3D Scene Guidance
不适用，本项目为纯2D界面。
