## 1. 产品概述

简化版"坦克大战"是一款经典街机风格的网页游戏，玩家控制坦克在地图中移动射击，摧毁敌方坦克并保护基地。
- 目标用户：喜欢经典街机游戏、怀旧游戏的玩家
- 核心价值：提供简单易上手但具有挑战性的坦克对战体验

## 2. 核心功能

### 2.1 用户角色
无需用户角色区分，单机游戏

### 2.2 功能模块
1. **游戏主界面**: 游戏画布、HUD信息显示、开始/暂停菜单
2. **游戏结束界面**: 胜利/失败提示、分数显示、重试选项

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 游戏主界面 | 游戏画布 | Canvas渲染游戏画面，包含玩家坦克、敌方坦克、地图元素、子弹、道具 |
| 游戏主界面 | HUD | 显示玩家生命值、剩余敌人数量、当前关卡、道具状态 |
| 游戏主界面 | 开始菜单 | 游戏标题、开始按钮、操作说明 |
| 游戏主界面 | 暂停菜单 | 暂停状态下显示继续/重新开始选项 |
| 游戏结束界面 | 胜利界面 | 显示胜利信息、最终分数、重玩按钮 |
| 游戏结束界面 | 失败界面 | 显示失败原因、重试按钮 |

## 3. 核心流程

### 3.1 游戏主流程
1. 玩家打开页面，看到开始菜单
2. 点击开始后，游戏初始化地图和实体
3. 玩家使用方向键移动坦克，空格键射击
4. 敌方坦克自动生成并随机移动射击
5. 子弹碰撞检测：摧毁敌人/砖墙，被铁墙阻挡
6. 击毁特定敌人掉落道具，玩家拾取获得增益
7. 满足胜利条件（消灭所有敌人）或失败条件（基地被毁/生命耗尽）时游戏结束
8. 显示结果界面，可选择重玩

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**: 军事风格 - 深绿色(#2d4a3e)、橄榄绿(#4a5d23)、沙色(#c9b896)
- **辅助色**: 红色(#e63946)用于危险/敌人、金色(#ffd700)用于道具
- **按钮风格**: 像素风格圆角按钮，带有轻微3D效果
- **字体**: 像素风格字体，标题24px，正文16px
- **布局**: 居中游戏画布，顶部HUD，底部控制说明
- **图标**: 像素风格坦克、爆炸、道具图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 游戏主界面 | 游戏画布 | 640x640像素Canvas，深色背景，网格地图 |
| 游戏主界面 | HUD | 左上角生命图标+数字，右上角敌人数量，道具状态栏 |
| 游戏主界面 | 开始菜单 | 居中标题"坦克大战"，像素风格开始按钮，操作说明 |
| 游戏结束界面 | 胜利界面 | 绿色主题，"胜利!"文字，星星动画效果 |
| 游戏结束界面 | 失败界面 | 红色主题，"游戏结束"文字，重试按钮 |

- 桌面优先设计，固定640x640游戏画布

## 5. 游戏规则详细说明

### 5.1 玩家操作
- 方向键（↑↓←→）：控制坦克移动
- 空格键：发射子弹
- 射击冷却：500ms（防止滥用）

### 5.2 AI行为
- 随机方向移动，遇到障碍物转向
- 随机间隔射击（1-3秒）
- 不会主动攻击基地（简化版）

### 5.3 碰撞规则
- 子弹 vs 敌人：敌人被摧毁，子弹消失
- 子弹 vs 砖墙：砖墙被摧毁，子弹消失
- 子弹 vs 铁墙：子弹被阻挡消失，铁墙完好
- 子弹 vs 草地：子弹穿过，草地完好
- 子弹 vs 基地：基地被摧毁，游戏失败
- 坦克 vs 墙壁：无法穿过
- 坦克 vs 草地：可以穿过（只遮挡视线）

### 5.4 道具系统
- 攻击提升：击毁第5、10个敌人时掉落，拾取后攻击力翻倍，持续15秒
- 生命增加：击毁第7个敌人时掉落，拾取后生命+1

### 5.5 胜负条件
- 胜利：消灭全部15个敌人
- 失败：玩家生命归零 或 基地被摧毁

### 5.6 可选功能
- 局时限制：3分钟，超时平局（可通过开关启用）
- 进度保存：localStorage保存最高分
- 难度分层：简单/普通/困难（影响AI速度和射速）
