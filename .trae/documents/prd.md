## 1. Product Overview

极简在线二维码生成工具，用户只需粘贴网址或文本链接，即可即时生成可右键保存的二维码图片。无需注册、登录或安装任何软件，专注于二维码生成这一个核心功能。

- 解决用户快速生成二维码的需求，无需复杂操作和额外软件安装
- 目标用户：需要快速生成二维码的普通用户，如分享链接、保存文本信息等场景

## 2. Core Features

### 2.1 User Roles
无需用户角色区分，所有功能匿名可用。

### 2.2 Feature Module
1. **主页面**: 输入框、二维码显示区、使用说明

### 2.3 Page Details
| Page Name | Module Name | Feature description |
|-----------|-------------|---------------------|
| 主页面 | 输入框 | 大而清晰的文本输入框，支持HTTP/HTTPS链接及纯文本，提示用户"粘贴你的网址或文本链接" |
| 主页面 | 即时生成 | 用户停止输入1秒后自动生成二维码，无需点击按钮 |
| 主页面 | 二维码显示 | 在输入框下方显示生成的二维码图片，确保清晰度和扫描成功率 |
| 主页面 | 保存功能 | 支持用户右键保存图片为PNG格式 |

## 3. Core Process

用户打开页面 → 在输入框粘贴/输入内容 → 等待1秒自动生成二维码 → 右键保存图片

```mermaid

    "D" --> "E[显示二维码图片]"
```

## 4. User Interface Design

### 4.1 Design Style
- **Primary Color**: 深灰/黑色 (#1a1a1a) 作为主色调，体现极简专业感
- **Secondary Color**: 白色 (#ffffff) 作为背景，确保对比度
- **Accent Color**: 渐变蓝紫色 (#667eea → #764ba2) 作为点缀，增加现代感
- **Button Style**: 无按钮设计，采用即时生成模式
- **Font**: 使用 Space Mono 作为标题字体（技术感），Noto Sans SC 作为正文字体
- **Layout Style**: 居中单列布局，大量留白，突出核心功能
- **Icon Style**: 简洁线条图标，无emoji

### 4.2 Page Design Overview
| Page Name | Module Name | UI Elements |
|-----------|-------------|-------------|
| 主页面 | Header | Logo + 标题，居中对齐，简洁字体 |
| 主页面 | 输入区域 | 大尺寸输入框，圆角设计，placeholder提示明显 |
| 主页面 | 二维码区域 | 白色背景卡片，二维码居中显示，带阴影效果 |
| 主页面 | 提示文字 | 小字号灰色文字，说明使用方法 |

### 4.3 Responsiveness
- Desktop-first 设计，适配大屏幕最佳体验
- 平板和手机端自适应布局，输入框和二维码区域垂直排列
- 触摸优化：输入框高度适配触摸操作

### 4.4 3D Scene Guidance
不适用
