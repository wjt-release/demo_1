# 坦克大战游戏 - 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品名称
坦克大战 (Tank Battle)

### 1.2 产品描述
一款基于 HTML5 Canvas 的经典坦克大战游戏复刻版，玩家控制坦克在地图中移动射击，摧毁敌方坦克并保护基地。

### 1.3 目标用户
- 怀旧游戏爱好者
- 休闲游戏玩家
- 喜欢经典街机游戏的用户

## 2. 核心功能需求

### 2.1 玩家操作 (P1 - 必须实现)
| 功能 | 操作方式 | 说明 |
|------|----------|------|
| 移动 | 方向键 (↑↓←→) | 控制坦克上下左右移动 |
| 射击 | 空格键 | 发射直线子弹 |
| 暂停 | P 键 | 暂停/继续游戏 |

### 2.2 AI 行为 (P1 - 必须实现)
- 敌方坦克自动生成（从地图顶部随机位置）
- 随机移动逻辑：遇障碍物改变方向
- 自动射击：随机间隔向当前方向发射子弹
- 与玩家交互：可被玩家子弹摧毁，也可摧毁玩家

### 2.3 地图系统 (P1 - 必须实现)
| 地形类型 | 颜色标识 | 特性 |
|----------|----------|------|
| 砖墙 | 橙色 | 可被子弹摧毁，阻挡移动 |
| 铁墙 | 灰色 | 不可摧毁，阻挡子弹和移动 |
| 草地 | 绿色 | 仅遮挡视线，不阻挡移动 |
| 基地 | 黄色 | 被摧毁则游戏失败 |
| 空地 | 黑色 | 可自由通行 |

### 2.4 碰撞判定 (P1 - 必须实现)
- 坦克与墙壁：无法穿越砖墙和铁墙
- 子弹与砖墙：子弹摧毁砖墙并消失
- 子弹与铁墙：子弹被阻挡消失（或反弹）
- 子弹与坦克：子弹摧毁坦克
- 子弹与基地：基地被摧毁，游戏失败

### 2.5 胜负判定 (P1 - 必须实现)
| 条件 | 结果 |
|------|------|
| 消灭全部敌人 (默认20个) | 胜利 |
| 玩家生命耗尽 (默认3条) | 失败 |
| 基地被摧毁 | 失败 |

### 2.6 道具系统 (P1 - 必须实现)
| 道具 | 效果 | 持续时间 |
|------|------|----------|
| 攻击提升 | 子弹伤害/射速提升 | 10秒 |
| 生命增加 | 玩家生命+1 | 永久 |

- 击毁指定敌人（每5个）掉落道具
- 道具在地图上显示5秒后消失
- 拾取后效果立即生效

## 3. 非核心功能需求 (P2 - 可选)

### 3.1 局时限制
- 单局限时3分钟
- 超时视为平局
- 可作为开关配置

### 3.2 操作约束
- 射速限制：最小射击间隔500ms
- 转向限制：平滑转向动画

### 3.3 进度保存
- 使用 localStorage 保存游戏进度
- 支持继续上一局或重新开始

### 3.4 难度分层
| 难度 | AI速度 | AI射速 | 敌人数量 |
|------|--------|--------|----------|
| 简单 | 1x | 1x | 15 |
| 普通 | 1.5x | 1.5x | 20 |
| 困难 | 2x | 2x | 30 |

### 4.2 视觉风格
- 复古像素风格
- 深色背景配霓虹色彩
- 经典8-bit音效风格（可选）

## 5. 技术要求

### 5.1 技术栈
- HTML5 Canvas
- 原生 JavaScript (ES6+)
- CSS3 样式

### 5.2 性能要求
- 60 FPS 流畅运行
- 单文件实现，无外部依赖
- 兼容主流浏览器
