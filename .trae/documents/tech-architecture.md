# 数据看板技术架构文档

## 1. 技术选型

### 1.1 前端框架
- **HTML5**: 页面结构
- **CSS3**: 样式与动画
- **JavaScript (ES6+)**: 交互逻辑

### 1.2 图表库
- **Chart.js 4.x**: 用于折线图和饼图
- **自定义 Canvas 绘制**: 用于热力图

### 1.3 字体
- **DM Sans**: 主字体，现代简洁
- **JetBrains Mono**: 数字展示字体

## 2. 项目结构

```
/workspace
├── index.html          # 主页面
├── styles.css          # 样式文件
├── app.js              # 主逻辑
└── .trae/documents/    # 文档目录
```

## 3. 模块设计

### 3.1 指标卡片模块
- 三个并排卡片
- 图标 + 数值 + 标签
- 渐变背景装饰

### 3.2 图表模块
- 销售趋势折线图
- 地区分布饼图
- 用户活跃度热力图

### 3.3 布局
- CSS Grid 布局
- 响应式断点设计

## 4. 配色方案

### 4.1 主色调
- 背景: #0f0f23 (深色主题)
- 卡片背景: #1a1a2e
- 主强调色: #6366f1 (靛蓝)
- 次强调色: #22d3ee (青色)

### 4.2 数据颜色
- 折线图: 渐变靛蓝到紫色
- 饼图: 多彩配色方案
- 热力图: 青色到靛蓝渐变

## 5. 动画设计

### 5.1 入场动画
- 卡片依次淡入
- 图表绘制动画

### 5.2 交互动画
- 悬停缩放效果
- 数据提示框动画

## 6. 数据结构

### 6.1 汇总指标
```javascript
{
  users: { value: 128456, change: 12.5 },
  conversionRate: { value: 3.24, change: 0.8 },
  dailyRevenue: { value: 89420, change: -2.1 }
}
```

### 6.2 销售趋势
```javascript
{
  labels: ['日期1', '日期2', ...],
  data: [1200, 1350, ...]
}
```

### 6.3 地区分布
```javascript
[
  { province: '广东', value: 25 },
  { province: '浙江', value: 18 },
  ...
]
```

### 6.4 活跃度热力图
```javascript
// 7天 x 24小时的二维数组
[
  [12, 8, 5, ...], // 第1天各小时活跃度
  [15, 10, 6, ...], // 第2天各小时活跃度
  ...
]
```
