# 产品需求文档 (PRD)

## 项目名称
QR Code Generator - 极简在线二维码生成工具

## 1. 产品概述

### 1.1 产品定位
一个极简主义的在线二维码生成工具，专注于"粘贴即生成"的核心体验。无需注册、登录或安装任何软件，用户只需粘贴网址或文本，即可即时获得可右键保存的二维码图片。

### 1.2 目标用户
- 需要快速生成二维码的普通互联网用户
- 营销人员、内容创作者
- 需要分享链接的移动端用户
- 追求效率的办公人群

### 1.3 核心价值主张
**零门槛、零等待、零干扰** - 三秒内完成从粘贴到保存的全流程

## 2. 功能需求

### 2.1 核心功能

#### F1: 文本输入
- 大型输入框，占据视觉中心位置
- 占位符文案："粘贴你的网址或文本链接"
- 支持HTTP/HTTPS链接及任意纯文本
- 输入框高度自适应（最小120px，最大300px）

#### F2: 即时生成
- 防抖机制：用户停止输入1秒后自动触发生成
- 无需点击"生成"按钮
- 生成过程显示加载动画（可选）
- 生成失败时显示友好错误提示

#### F3: 二维码显示
- 二维码尺寸：256x256像素（桌面端），200x200像素（移动端）
- 高容错级别（Level H），确保扫描成功率
- 白色边距（4模块宽度），确保扫描兼容性
- PNG格式输出，保证清晰度

#### F4: 保存功能
- 支持右键"图片另存为"
- 提供下载按钮作为备选方案
- 默认文件名：qrcode-[时间戳].png

### 2.2 非功能需求

#### NFR1: 性能
- 首屏加载时间 < 1秒
- 二维码生成时间 < 500ms
- 总资源大小 < 100KB（不含QR库）

#### NFR2: 兼容性
- 支持主流浏览器：Chrome、Firefox、Safari、Edge
- 响应式设计：适配桌面、平板、手机
- 移动端触控友好

#### NFR3: 安全性
- 纯前端生成，无数据传输
- 无Cookie、无追踪
- HTTPS部署

#### NFR4: 可访问性
- 符合WCAG 2.1 AA标准
- 键盘导航支持
- 屏幕阅读器友好

## 3. 用户体验设计

### 3.1 界面布局
```
┌─────────────────────────────────────────┐
│              [Logo/标题]                 │
│                                         │
│  ┌─────────────────────────────────┐   │
│  │                                 │   │
│  │   粘贴你的网址或文本链接          │   │
│  │                                 │   │
│  └─────────────────────────────────┘   │
│                                         │
│           ┌───────────┐                │
│           │           │                │
│           │  QR Code  │                │
│           │           │                │
│           └───────────┘                │
│                                         │
│           [下载二维码]                   │
│                                         │
└─────────────────────────────────────────┘
```

### 3.2 交互流程
1. 用户进入页面 → 焦点自动定位到输入框
2. 用户粘贴/输入内容 → 1秒后自动生成二维码
3. 二维码显示 → 用户可右键保存或点击下载按钮

### 3.3 视觉风格
- **风格定位**: 日式极简 + 工业设计感
- **主色调**: 深灰背景 + 白色输入区 + 青色点缀
- **字体**: 等宽字体作为主要字体，体现技术感
- **动效**: 微妙的渐入动画，不打扰用户注意力

## 4. 技术约束

### 4.1 技术栈
- 纯HTML/CSS/JavaScript（无框架依赖）
- QR Code生成库：qrcode.js（轻量级，< 10KB）
- 无后端服务

### 4.2 部署要求
- 静态托管即可（GitHub Pages、Vercel、Netlify等）
- HTTPS强制跳转

## 5. 成功指标

### 5.1 关键指标
- 页面加载时间 < 1秒
- 二维码生成成功率 > 99.9%
- 移动端可用性评分 > 90

### 5.2 用户满意度
- 界面简洁度：用户能在3秒内理解如何使用
- 功能满意度：一键生成，无需学习成本

- 响应式设计

### V1.1 (未来规划)

### V2.0 (未来规划)
