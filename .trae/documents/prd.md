# 产品需求文档 (PRD)

## 项目名称
QR Snap - 极简在线二维码生成工具

## 1. 产品概述

### 1.1 产品定位
QR Snap 是一款极简主义的在线二维码生成工具，专注于"粘贴即生成"的核心体验。无需注册、登录或安装任何软件，用户只需粘贴网址或文本，即可即时获得可保存的二维码图片。

### 1.2 目标用户
- 需要快速生成二维码的普通用户
- 营销人员、内容创作者
- 需要分享链接的商务人士
- 不想安装额外软件的轻量用户

### 1.3 核心价值主张
**极致简单** - 三步完成：粘贴 → 生成 → 保存

## 2. 功能需求

### 2.1 核心功能

#### F1: 文本输入框
- 大而清晰的输入区域
- 占位符提示："粘贴你的网址或文本链接"
- 支持多行文本输入
- 支持 HTTP、HTTPS 链接及任意纯文本

#### F2: 即时生成
- 输入后自动触发生成（防抖 1 秒）
- 无需点击"生成"按钮
- 实时预览二维码

#### F3: 二维码显示
- 高清晰度二维码图片
- 足够的尺寸保证扫描成功率
- 支持右键保存为 PNG 格式

### 2.2 非功能需求

#### NFR1: 性能
- 页面加载时间 < 2 秒
- 二维码生成时间 < 500ms
- 无外部 API 依赖

#### NFR2: 响应式设计
- 桌面端：居中布局，输入框与二维码并排或上下排列
- 平板端：自适应布局
- 移动端：垂直堆叠布局

#### NFR3: 无障碍性
- 语义化 HTML 结构
- 键盘可访问
- 适当的 ARIA 标签

#### NFR4: 安全性
- 纯前端处理，无数据传输
- 无 Cookie 追踪
- 无第三方分析脚本

├─────────────────────────────────────────────┤

### 3.2 交互流程
1. 用户进入页面，看到干净的输入框
2. 粘贴或输入内容
3. 停止输入 1 秒后自动生成二维码
4. 用户右键保存二维码图片

### 3.3 视觉风格
- **风格**: 日式极简主义 + 现代科技感
- **色调**: 深色背景配亮色二维码区域，或纯白背景配黑色二维码
- **字体**: 独特的显示字体 + 清晰的正文字体
- **动效**: 微妙的输入反馈和二维码生成动画

## 4. 技术约束

### 4.1 必须遵守
- 纯前端实现，无需后端服务
- 使用 Canvas API 生成二维码
- 单 HTML 文件或极简项目结构

### 4.2 技术选型
- HTML5 + CSS3 + Vanilla JavaScript
- 二维码库：qrcode.js (轻量级，CDN 可用)
- 无框架依赖，保持极简

## 5. 成功指标

### 5.1 用户体验指标
- 用户能在 5 秒内完成首次二维码生成
- 二维码扫描成功率 > 99%
- 页面完全加载时间 < 2 秒

### 5.2 技术指标
- 零后端依赖
- 零用户数据收集
- 100% 前端处理

## 6. 发布计划

### 6.1 MVP 版本 (v1.0)
- 基础二维码生成功能
- 响应式布局
- PNG 格式保存

### 6.2 未来迭代 (可选)
- 自定义二维码颜色
- 添加 Logo 到二维码中心
- 批量生成功能
