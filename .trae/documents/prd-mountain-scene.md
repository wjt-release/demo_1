## 1. 产品概述

一个沉浸式 3D 山脉地形可视化场景，展示包含悬崖、河流的自然地貌，支持昼夜光照动态变化。用户可自由探索场景，切换等高线显示，体验真实的自然景观。

- **目标用户**: 地理爱好者、教育工作者、游戏开发者、视觉艺术爱好者
- **核心价值**: 提供高度沉浸感的自然地貌可视化体验，展示地形数据的艺术化呈现

## 2. 核心功能

### 2.1 功能模块

1. **3D 地形渲染**: 山脉、悬崖、河流的真实感渲染
2. **昼夜系统**: 动态光照变化，模拟日出日落
3. **交互控制**: 拖动旋转、缩放、平移
4. **等高线切换**: 可开关的等高线叠加显示

### 2.2 页面详情

| 模块名称 | 功能描述 |
|---------|---------|
| 地形渲染 | 使用噪声算法生成山脉地形，包含悬崖陡坡和河流谷地 |
| 昼夜循环 | 太阳位置动态变化，天空颜色渐变，环境光强度调节 |
| 交互控制 | 鼠标拖动旋转视角，滚轮缩放，右键平移 |
| 等高线 | 可切换的等高线叠加层，展示地形高度信息 |
| 动画过渡 | 所有状态变化均有平滑动画过渡效果 |

## 3. 核心流程

用户打开页面后，自动加载 3D 山脉场景。用户可以：
1. 拖动鼠标旋转视角探索地形
2. 滚轮缩放查看细节或全景
3. 点击按钮切换昼夜模式或自动循环
4. 开关等高线显示

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**: 自然大地色系 - 深棕、墨绿、天蓝、暖橙（日出/日落）
- **辅助色**: 白色等高线、金色阳光、银色月光
- **字体**: 使用优雅的无衬线字体，如 Outfit 或 Sora
- **布局**: 全屏沉浸式 3D 场景，左下角控制面板
- **图标风格**: 简约线性图标，带有微妙发光效果

### 4.2 页面设计

| 区域 | UI 元素 |
|-----|--------|
| 主场景 | 全屏 3D Canvas，占据整个视口 |
| 控制面板 | 半透明深色背景，圆角卡片，包含昼夜切换、等高线开关 |
| 信息提示 | 右下角显示当前时间/光照状态 |
| 加载动画 | 山脉轮廓剪影加载动画 |

### 4.3 响应式设计

- 桌面端优先，支持鼠标完整交互
- 移动端支持触摸拖动和双指缩放
- 控制面板在小屏幕上自动收缩为图标

### 4.4 3D 场景指导

**环境氛围**:
- 日间: 明亮的天空蓝，温暖的阳光，清晰的能见度
- 夜间: 深蓝星空，柔和的月光，远处的雾气效果

**光照设置**:
- 主光源: 方向光模拟太阳/月亮，随时间移动
- 环境光: 半球光提供天空和地面的反射光
- 雾效: 指数雾增加深度感

**相机设置**:
- 初始位置: 俯视角度，能看到整体地形
- 运动: 平滑的惯性阻尼，自然的旋转和缩放

**地形材质**:
- 高度渐变: 低处绿色草地 → 中部棕色岩石 → 高处白色雪顶
- 悬崖: 深灰色岩石纹理
- 河流: 蓝绿色半透明水面，带有流动效果

**交互与动画**:
- 昼夜过渡: 30秒完成一个完整循环（可调节）
- 等高线切换: 0.5秒淡入淡出
- 相机移动: 惯性阻尼，平滑过渡
