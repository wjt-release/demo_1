# 3D Mountain Scene

A 3D interactive mountain scene built with Three.js.

## Features
-   **Procedural Terrain**: Mountains with cliffs and valleys generated using Simplex noise.
-   **Water System**: Dynamic river simulation.
-   **Day/Night Cycle**: Realistic lighting changes with sun movement and atmospheric color shifts.
-   **Interaction**: Drag to rotate, zoom to explore.
-   **Contour Lines**: Toggleable contour lines for terrain visualization.

## Setup

1.  Install dependencies:
    ```bash
    npm install
    ```

2.  Run the development server:
    ```bash
    npm run dev
    ```

3.  Open the preview URL to view the scene.

## Controls
-   **Left Mouse Drag**: Rotate camera.
-   **Scroll**: Zoom in/out.
-   **Right Mouse Drag**: Pan camera.
-   **UI Panel**: Toggle contour lines.
