## 1. 产品概述

数据看板是一个企业级数据可视化平台，为管理层和运营团队提供实时业务数据洞察。
- 解决数据分散、难以快速获取关键业务指标的问题
- 目标用户：企业管理层、数据分析师、运营人员

## 2. 核心功能

### 2.1 用户角色

| 角色 | 访问方式 | 核心权限 |
|------|----------|----------|
| 管理员 | 账号登录 | 查看所有数据、导出报表 |
| 分析师 | 账号登录 | 查看数据、创建自定义报表 |
| 访客 | 链接访问 | 查看公开数据 |

### 2.2 功能模块

1. **数据看板页面**: 顶部汇总指标、销售趋势图、地区分布图、用户活跃度热力图

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 数据看板 | 顶部汇总指标 | 显示用户数、转化率、日均收入等关键指标 |
| 数据看板 | 销售趋势折线图 | 展示近30天销售数据趋势变化 |
| 数据看板 | 地区分布饼图 | 展示不同省份销售占比分布 |
| 数据看板 | 用户活跃度热力图 | 展示用户在日-小时维度的活跃分布 |

## 3. 核心流程

用户访问数据看板页面，系统自动加载并展示各项数据可视化图表。用户可以快速浏览关键指标，通过图表交互深入了解数据细节。

```mermaid
flowchart TD
    "用户访问看板" --> "加载汇总指标"
    "加载汇总指标" --> "渲染销售趋势图"
    "渲染销售趋势图" --> "渲染地区分布图"
    "渲染地区分布图" --> "渲染活跃度热力图"
    "渲染活跃度热力图" --> "用户交互探索"
    "用户交互探索" --> "查看详细数据"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**: 深蓝渐变背景 (#0f172a → #1e293b)，搭配青色强调色 (#06b6d4)
- **卡片风格**: 毛玻璃效果卡片，圆角 16px，微妙阴影
- **字体**: 使用 Space Grotesk 作为标题字体，DM Sans 作为正文字体
- **布局**: 响应式网格布局，顶部指标横向排列，图表区域 2x2 网格
- **图标风格**: 线性图标，搭配渐变色彩点缀

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 数据看板 | 顶部汇总指标 | 渐变背景卡片、大号数字、趋势箭头、微动画 |
| 数据看板 | 销售趋势折线图 | Chart.js 折线图、渐变填充、交互提示 |
| 数据看板 | 地区分布饼图 | Chart.js 饼图、图例、悬停高亮 |
| 数据看板 | 用户活跃度热力图 | Chart.js 热力图、色阶渐变、坐标轴标签 |

### 4.3 响应式设计

- 桌面优先设计，大屏展示效果最佳
- 平板端：图表区域调整为 2 列布局
- 移动端：单列堆叠布局，保持可读性

### 4.4 动效设计

- 页面加载时卡片依次淡入动画
- 数字指标计数动画
- 图表数据加载时的骨架屏效果
- 悬停时卡片轻微上浮效果
